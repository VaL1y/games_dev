# Игры

## Сердце прилива — лабиринт с костями

Текущая версия находится в [1-labirint-s-kostyamy-godot](1-labirint-s-kostyamy-godot).

- [Готовая Windows-сборка](https://github.com/VaL1y/games_dev/releases) — распакуйте ZIP целиком и запустите `HeartOfTide.exe`.
- [Книга сюжета](1-labirint-s-kostyamy-godot/story/BOOK.md) — редактируемый источник событий и диалогов.
- [Инструкция разработчика](1-labirint-s-kostyamy-godot/README.md).

Одиночная сюжетная глава: шесть карт, 252 события, выбор движения в пределах броска кубика. Аркада рассчитана на локальную компанию. Сетевой режим пока не реализован.

Для работы с исходниками откройте `1-labirint-s-kostyamy-godot/project.godot` в Godot 4.7.2. Движок и экспортные шаблоны в Git не включены. В готовой сборке папка `story` лежит рядом с EXE: тексты и карты можно менять без пересборки.
